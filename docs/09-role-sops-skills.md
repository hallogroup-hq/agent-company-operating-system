# 9. Separate Role SOP from Narrow Skills

## Goal

Mencegah dua ekstrem:

- role terlalu kosong sehingga agent improvisasi setiap saat;
- role berubah menjadi ratusan micro-skill yang sulit dipelihara.

## Model

```text
AGENT / ROLE = profession
ROLE DELIVERY SOP = default way of working
SKILL = narrow technique
```

## Example

Engineering umbrella:

```text
UNDERSTAND → INSPECT → PLAN → IMPLEMENT → TEST → REVIEW → VERIFY → HANDOFF
```

Creative/Marketing umbrella:

```text
retrieve context
→ define job
→ classify problem
→ strategy
→ creative development
→ specialist execution
→ QA
→ handoff/state update
```

System stewardship umbrella:

```text
observe
→ reproduce safely
→ diagnose
→ assess risk
→ checkpoint
→ repair
→ test
→ verify
→ rollback if worse
→ ledger
→ explain
```

## Step-by-step

1. Audit existing skills.
2. Identify role-level recurring workflow.
3. Create one umbrella SOP when justified.
4. Keep narrow proven craft skills.
5. Retire duplicates only after evidence.
6. Jangan membuat skill untuk setiap prompt pattern.

## PASS criteria

Agent punya "cara kerja profesi" yang konsisten tanpa kehilangan fleksibilitas.
