# 8. Build Shared Knowledge Without Creating a Second Task Manager

## Goal

Pisahkan durable meaning dari execution state.

## Recommended separation

```text
Shared notes / knowledge base
= business, client, brand, project context, decisions, canon, research

Kanban / task board
= task, owner, status, dependency, blocker, run, review, completion evidence

Agent private memory
= personal learning / relationship / user-specific experience

Cron
= rhythm / time trigger

Identity files
= personality / protected identity
```

## Suggested knowledge taxonomy

```text
Founder / Operator
Businesses / Ventures
Active Projects
Clients & Brands
Characters / Canon (if relevant)
Systems & Playbooks
Research
Source Artifacts
Decisions & Learnings
```

## Retrieval rules

- retrieve before invent;
- load the smallest relevant set;
- jangan ingest seluruh vault untuk routine request;
- search existing canonical note before create;
- update before duplicate;
- pisahkan fact, decision, hypothesis, recommendation.

## Project HQ

Untuk substantial project, buat Project HQ yang bisa menjawab:

- objective;
- why it matters;
- owner;
- contributors;
- scope/out-of-scope;
- decisions;
- canonical sources;
- artifacts;
- constraints;
- open questions;
- execution board slug.

## PASS criteria

Agent bisa menemukan durable project truth tanpa mengandalkan chat history satu orang.
