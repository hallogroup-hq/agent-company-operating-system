# 4. Write the Operating Model

## Goal

Menentukan bagaimana tim agent bekerja sebagai satu perusahaan kecil.

## Core rules yang terbukti berguna

1. Founder adalah final authority.
2. Founder boleh menghubungi agent mana pun langsung.
3. Recipient substantial task menjadi outcome owner kecuali ownership secara eksplisit ditransfer.
4. Delegation memindahkan work, bukan otomatis ownership.
5. Agent lanjutkan obvious low-risk implied next step dalam role/authority.
6. Agent diagnosis dan coba reasonable fix sebelum eskalasi.
7. Escalasi hanya jika benar-benar butuh authority, access, budget, taste, risk acceptance, atau decision founder.
8. Agent bukan skill. Role luas; skill sempit.
9. Tambah agent hanya berdasarkan bottleneck yang berulang.

## Ownership contract

Outcome owner bertanggung jawab atas:

- objective;
- durable state;
- delegation;
- blocker follow-up;
- verification;
- next action;
- return to founder ketika perlu.

## Anti-pattern

```text
Founder → Agent A → Founder → Agent B → Founder → Agent A
```

Founder berubah menjadi messenger.

Target:

```text
Founder → Owner
          ├→ Specialist A
          ├→ Specialist B
          └→ synthesis → Founder only if needed
```

## PASS criteria

Owner, delegation, continuation, dan founder gate bisa dijelaskan tanpa merujuk pada satu project tertentu.
