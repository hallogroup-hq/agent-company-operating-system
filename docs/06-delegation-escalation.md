# 6. Delegation and Escalation

## Goal

Agent saling bekerja sama tanpa founder menjadi kurir dan tanpa task kehilangan owner.

## Delegation contract

Ketika owner mendelegasikan:

- specialist menerima bounded objective;
- specialist mengembalikan result/evidence;
- owner tetap memegang overall outcome;
- ownership hanya pindah jika eksplisit.

## Escalation flow

Sebelum eskalasi:

```text
investigate
→ try reasonable fix
→ ask specialist
→ identify alternatives
→ escalate only if founder is actually required
```

## Escalation format

Gunakan format konsisten:

```text
Problem
Impact
Already attempted
Options
Recommendation
Need from founder
```

## Direct delegation vs durable board

Gunakan direct delegation untuk quick bounded help.

Gunakan durable task board bila:

- substantial;
- multi-step;
- cross-agent;
- punya dependency;
- butuh review;
- harus survive setelah chat selesai.

## PASS criteria

Tidak ada project yang orphan hanya karena conversation selesai.
