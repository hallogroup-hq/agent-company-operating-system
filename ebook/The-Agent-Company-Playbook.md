## Core thesis

```text
Identity tells the agent who it is.
Role tells it what it owns.
Knowledge tells it what is true.
Kanban tells it what is happening.
Triggers tell it when to move.
Verification tells us whether it actually worked.
```

## Proven implementation order

```text
Protect identity
→ define roles
→ audit runtime
→ operating model
→ authority
→ delegation
→ lifecycle
→ shared knowledge
→ role SOPs
→ Kanban rules
→ real-project pilot
→ refine native semantics
→ event-first autonomy
→ multi-project isolation
→ evidence-based roster growth
```
